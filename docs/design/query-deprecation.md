# Queryの非推奨化

2026-10-04。Issue #236に従い、Queryの必要性を再評価するまで利用者向けUIから外す。

- 左ナビゲーションの「Query・検索別名」と、InspectorのQueryパネルを外す。
- Queryの実行・保存をコマンドパレットから外し、Ctrl+Shift+Qを解除する。
- 既存のコマンドIDへの要求も拒否し、実行・保存を起こさない。
- Queryや検索別名の保存データ、バックアップ形式、既存の読み取り・保存APIは保持する。
  検索別名の編集入口は休止するが、登録済み別名を通常の検索で使う処理は維持する。
- 再評価のため、Queryエンジン・Controller・旧パネルとその単体テストは残す。
  AppはQueryの起動時読込・状態・実行処理を組み込まない。

Datalogエクスポート、ルールエンジンの試作、上部検索欄への再導入はこの変更に含めない。 Issue
#236は再評価と再導入の検討課題として継続する。
