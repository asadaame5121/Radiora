# Radiora v2 UIデザイン改善計画

## 1. 背景と課題意識

Radiora v2 のPoC画面（アウトライナー）における実用上の摩擦を解消し、思考の記録と長文執筆の体験を向上させるためのUI改善方針を本ドキュメントにまとめる。

### 観測された課題（実画面フィードバックより）
1. **ノード上のUI被り**: ノード右上に表示されている「表示 Markdown ∨」というフローティングドロップダウンが本文の上に覆いかぶさり、文章の視認性および編集を著しく阻害している。
2. **プレビューと編集のモード切り替え摩擦**: 普通のアウトライナー入力において過度なMarkdown構造化は不要であり、太字や斜体などの軽量な装飾で十分である。入力時は生テキスト/Live表示、フォーカスが外れたらリッチなプレビュー表示になるのが望ましい。
3. **長文執筆環境の不足**: アウトラインの1ノードに長文を打ち込む場合、アウトライナーの標準ノード表示だけでは狭く執筆しづらいため、特定の思考に集中して長文を推敲できる専用の「長文編集モード」が必要とされている。

---

## 2. 決定した改善方針

ヒアリング（/grill-me）に基づき、以下の4つの柱でUI改善を行う。

### 2.1 ノードインライン編集の文字被り解消とフォーカス連動
- **浮遊UIの廃止**: `MarkdownEditor.svelte` 内の右上ドロップダウン（`.markdown-editor-mode`）を完全に削除する。
- **フォーカス連動切り替え**:
  - ノード選択/フォーカス時 (`focus`): 編集モード（テキスト入力・Live Preview）
  - フォーカス解除時 (`blur`): プレビューモード（Markdown描画）
- **プレビュー固定/手動切替**: ショートカットキー（`Ctrl+M` / `Cmd+M`）やコマンドパレットからプレビュー表示の固定／解除を手動で切り替え可能にする。

### 2.2 隣接ペイン（分割ビュー方式）による長文集中編集モード
- **画面レイアウト**: アウトライン構造の隣に専用の「長文集中編集ペイン」を並べて開く（マルチペイン構造の拡張）。
- **利点**: アウトライン全体で文脈を確認・参照しながら、目的の思考ノード本文を広々としたエディタで集中して推敲・執筆できる。
- **起動トリガー**:
  - ノードのダブルクリック
  - キーボードショートカット（`Ctrl+Shift+Enter` など）
  - コマンドパレットからの操作
  - 右クリックコンテキストメニュー

### 2.3 コマンドパレット（Ctrl+K）およびショートカット操作の拡充
- **柔軟な操作ベース**: 画面上のボタンを増やさず、すべての主要操作（表示モード切替、長文ペイン起動、フォーカス操作等）をコマンドパレット（`Ctrl+K`）およびショートカットキーから実行可能にする。

### 2.4 全体UIのトーン＆マナー・デザイン調整
- **レイアウトの維持と質感向上**: 3カラム構成（左サイドバー、中央アウトライン、右Inspector）および上部ヘッダーの全体配置は変更せず維持する。
- **視認性の磨き上げ**:
  - ノードのパディング、フォントサイズ、選択枠（フォーカスリング）の洗練
  - 右側Inspectorのパネル枠線、見出しコントラスト、ボタン感触の微調整
  - 余白（spacing）の統一により、ノイズのない洗練されたモダンダークUIを実現する。

## 4. 検証・受け入れ条件

1. **品質検証**
   - `deno task verify` （Svelte型チェック、UIコントラクトテスト、ビルド検証）がエラー無く通過すること。
2. **手動・見た目の確認**
   - `deno task dev` (Vite) で起動し、ノード入力時にテキストの上にドロップダウン等の被りが発生しないこと。
   - フォーカスを外した際にプレビュー化されること。
   - コマンドパレットやショートカット、ダブルクリックから隣接長文ペインが開いて快適に長文編集を行えること。
   - UIの余白・コントラスト・枠線が洗練されていること。
