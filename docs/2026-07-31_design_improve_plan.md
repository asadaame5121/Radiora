# Radiora v2 UIデザイン改善計画

## 1. 背景と位置づけ

Radiora v2
のPoC画面（アウトライナー）で観測した摩擦を解消し、思考の記録と長文執筆を往復できるようにするための改善計画である。

当初は「アウトラインの隣に長文編集ペインを置く」案を検討した。しかし、構造を見る場所と長文に集中する場所を同じ中央ワークスペースで切り替える方針に変更した。この文書では、過去の意図を残しつつ、現行仕様を実施済み・継続・破棄した案に分けて記録する。

### 観測された課題

1. **ノード上のUI被り**: 右上の「表示 Markdown」選択UIが本文に重なり、視認性と編集を阻害していた。
2. **プレビューと編集の切り替え摩擦**:
   軽いアウトライン編集では、都度表示モードを選ぶより、フォーカスに応じて編集とプレビューが切り替わる方が自然だった。
3. **長文執筆環境の不足**: 一つの項目を推敲するとき、通常の行内編集だけでは表示領域が不足した。

## 2. 現行仕様（実施済み）

### 2.1 フォーカス連動Markdown表示

- 浮遊していた `.markdown-editor-mode` の表示選択UIは撤去対象とし、本文上にモード選択を重ねない。
- 項目本文はフォーカス時に編集表示へ移り、フォーカスを外すとMarkdownプレビューへ戻る。
- Overtypeを初期化できない場合はtextareaへフォールバックする。フォーカス・blurの意味はこのフォールバックでも一致させる。
- 通常のアウトライン編集では、表示モード固定や分割プレビューを必須機能にしない。

### 2.2 中央ペインへ展開する長文編集

- 選択中の項目を「長文編集」で開くと、中央ペインのアウトライン表示を長文編集モードへ切り替える。
- 長文編集はパンくず、項目名、編集／プレビュー、保存、キャンセルを持つ。右側インスペクターは文脈・操作のために維持する。
- 保存は選択中の項目本文へ反映し、未保存の変更をキャンセルするときは確認を求める。
- このモードは専用の原稿ビューを恒久的に増やすものではなく、アウトラインと集中執筆を往復する中央ワークスペースの状態である。

### 2.3 右側インスペクターと画面構成

- 通常のアウトライン画面は、左ナビゲーション、中央ワークスペース、右側インスペクターで構成する。
- インスペクターは幅を変更でき、不要なときは折りたためる。選択中の項目の関係、履歴、関連操作を扱う。
- 系統・比較などの専用ビューでは、中央ワークスペースを全面利用し、インスペクターを表示しない。

### 2.4 参照と意味関係の入力は分離する

- `[[` は本文内の内部参照補完を始め、正準保存時には不変IDを含む `radiora://`
  Markdownリンクとして保存する。内部参照はBacklinkを作るが、意味関係を暗黙には作らない。
- `@` は意味関係を作る相手Workの検索を始める。本文へMarkdown内部参照を暗黙挿入しない。
- 未解決の `@`
  候補は未配置Workとして作成できるが、内部参照の補完と同じ操作・同じ副作用として扱わない。

## 3. 継続する改善

- ノードの余白、選択リング、文字サイズ、コントラストを調整し、長時間の編集でも選択文脈を見失いにくくする。
- キーボード操作、コマンドパレット、インスペクターから同じ主要操作へ到達できるようにする。ただし、長文編集への導線は実利用を見て増やす。
- 長文編集と通常アウトラインの遷移、保存失敗、フォーカス移動を手動確認とUIコントラクトテストで継続的に確認する。
- 画像、表、常時分割プレビューは初期採用範囲に含めず、ドッグフーディングで必要性が確認された場合に再評価する。

## 4. 破棄した案と理由

### 隣接長文編集ペイン（分割ビュー方式）

アウトラインの隣に専用の長文ペインを常設し、ダブルクリック、ショートカット、コマンドパレット、コンテキストメニューから開く案を検討した。

この案は**破棄した**。長文編集を中央ペインへ展開する現行仕様の方が、限られた画面幅で編集領域を確保しつつ、右側インスペクターの文脈を保てるためである。以後、隣接ペインを前提にしたUI・受け入れ条件は採用しない。

## 5. 実装対応と検証観点

| 領域                                                                               | 現行の責務                                                                                          |
| ---------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| `src/ui/MarkdownEditor.svelte`                                                     | フォーカス時の編集表示、blur時のプレビュー表示、本文上に重ならないモード制御                        |
| `src/ui/markdown_editor_adapter.ts` / `src/ui/overtype_markdown_editor_adapter.ts` | Overtypeとtextareaフォールバックの共通アダプター、focus / blurの通知                                |
| `src/ui/App.svelte`                                                                | 中央ペインの長文編集状態、保存・キャンセル、`[[`内部参照と`@`意味関係入力の分離、インスペクター状態 |
| `src/ui/styles.css`                                                                | 中央ワークスペース、可変幅・折りたたみ可能なインスペクター、長文編集時の視認性                      |

受け入れ時には、少なくとも次を確認する。

1. `deno task verify` が成功すること。
2. 本文上に表示選択UIが重ならず、フォーカス時は編集表示、blur時はプレビュー表示になること。
3. 長文編集が中央ペインに展開し、保存・キャンセルと未保存変更の確認が正しく動くこと。
4. `[[`内部参照が意味関係を作らず、`@`意味関係入力が本文参照を挿入しないこと。
5. インスペクターの幅変更・折りたたみと、系統・比較ビューでの中央ワークスペース全面表示が選択文脈を損なわないこと。
